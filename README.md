# Лопни пузыри — демо-сборка для проверки вёрстки

Это версия для RuStore с **имитацией** рекламного баннера: полоса внизу экрана
занимает ровно столько же места, сколько нативный баннер в APK.

- Игра: https://vadim2451782.github.io/bubble-pop-demo/
- Как проверять: Chrome → F12 → Ctrl+Shift+M (режим устройства) → выбрать телефон.
- Настоящая реклама Яндекса показывается только в APK, здесь — заглушка.
